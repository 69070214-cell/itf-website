# มื้อไหนดี? — Food Randomizer

เว็บไซต์สุ่มเมนูอาหารแบบหน้าเดียว (Single Page) สร้างด้วย HTML, CSS และ Vanilla JavaScript
เมื่อกดปุ่มสุ่ม รูปภาพ ชื่อเมนู คำอธิบาย และราคาจะเปลี่ยนตามรายการที่สุ่มได้ทันที

## ฟีเจอร์

- Navbar อยู่ด้านบนสุดและตรึงไว้ขณะเลื่อนหน้า
- การ์ดแสดงเมนูสุ่มพร้อมรูปภาพ ชื่อเมนู คำอธิบาย ราคา เวลาเตรียม และประเภทอาหาร
- ปุ่มสุ่มเมนู 3D ดีไซน์เฉพาะ พร้อมแอนิเมชันตอนสุ่ม
- เมนูทั้งหมด 8 รายการ และการ์ดแสดงรายการอาหารทั้งหมด
- สุ่มแล้วไม่ซ้ำเมนูเดิมทันที
- กด `Space` เพื่อสุ่มได้ ขณะไม่ได้โฟกัสปุ่มหรือลิงก์
- รองรับหน้าจอมือถือ แท็บเล็ต และเดสก์ท็อป
- ใช้ Google Fonts (IBM Plex Sans Thai / Bricolage Grotesque)

## ไฟล์ในโปรเจกต์

```text
week15-ai/
├── index.html
├── styles.css

└── assets/

        ├── burger.jpg
        ├── salad.jpg
        ├── pasta.jpg
        ├── pancake.jpg

```

## แก้ไขเมนูหรือรูปภาพ

1. เปิด `app.js` และแก้ไขข้อมูลในอาร์เรย์ `FOODS`
2. เปลี่ยนรูปภาพได้โดยแทนไฟล์ใน `assets/images/` ด้วยชื่อไฟล์เดิม
   หรือแก้ค่า `image` ในข้อมูลเมนูให้ตรงกับไฟล์ใหม่
3. หากเพิ่มจำนวนเมนู ระบบจะนับจำนวนและแสดงรายการทั้งหมดให้อัตโนมัติ

## เปิดเว็บไซต์ในเครื่อง

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที หรือใช้ local server

```bash
python -m http.server 4173
```

แล้วเปิด <http://localhost:4173>

## Deploy บน Vercel

```bash
npx vercel --prod
```

โปรเจกต์เป็นเว็บไซต์แบบ Static ไม่ต้องมีขั้นตอน build
